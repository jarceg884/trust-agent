Work on a server or VPS? Use the CLI

The same governed agent, installed from your terminal in one command. It comes pre-bound to hermes-dl-e2e — your device enrolls automatically on first run and an admin approves it, exactly like the desktop app.

curl -fsSL http://127.0.0.1:8000/download/hermes-dl-e2e/cli | bash

Requirements: Linux, macOS or WSL2 with bash, curl and tar. The installer adds the Hermes CLI (official installer) if it is not present, plus the governance plugin and your organization's branding. On a headless server, run trust-login once from a machine with a browser and copy the resulting id-token.txt over.

1 · Download & install

Unpack and run ./install.sh. It installs the full agent with your organization's branding preconfigured.

2 · Sign in once

Run trust-login and authenticate with your organization account (SSO + MFA) in the browser.

3 · Governed automatically

Your device enrolls itself on first run. Once your admin approves it, organization policies apply to every session.
